# Employee Data Analysis (EDA)

## Project Overview

This project performs Exploratory Data Analysis (EDA) on an employee dataset using Python. The objective is to understand employee demographics, salary distribution, department-wise performance, and other key business insights through data visualization and statistical analysis.

## Objectives

* Understand the structure of the dataset.
* Clean and preprocess the data.
* Perform statistical analysis.
* Visualize important patterns and trends.
* Generate business insights from the data.

## Dataset Information

The dataset contains employee-related information such as:

* Employee ID
* Name
* Age
* Gender
* Department
* Salary
* Experience
* Performance Score
* Education Level
* City

## Tools and Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Exploratory Data Analysis Performed

* Dataset overview
* Data types inspection
* Missing value analysis
* Duplicate value detection
* Descriptive statistics
* Univariate analysis
* Bivariate analysis
* Correlation analysis
* Outlier detection
* Data visualization

## Visualizations

The project includes:

* Histograms
* Count plots
* Bar plots
* Box plots
* Violin plots
* Scatter plots
* Pair plots
* Heatmaps

## Key Insights

* The salary distribution shows variation across departments.
* Employee performance differs among departments.
* Certain variables exhibit positive correlation.
* Some numerical features contain outliers.
* Gender distribution varies across departments.
